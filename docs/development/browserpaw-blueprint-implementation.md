## Reproduced & Resolved Integration Defects

2026-10-30 Observation & exit additions: Tier-1 fast budgets and background cross-frame budgets must prioritize focus, errors, dynamic alerts, and associated form/result regions before rotating among equal candidates; standard pagination shares this priority. Fast extraction integrates controls, content, and scope/exclude boundaries within Shadow roots; ARIA names avoid cross-tree ID borrowing. Constructed stylesheet replacement invalidates document caches even with identical CSS text. Self-created REPL clients cleanly release their own MCP sessions without cancelling persistent tasks; external client injection retains existing exit handling. These changes remain in development verification; historical defects reproduced in legacy runtimes cannot be marked as passed without fresh live trials.

2026-10-30 Development additions: Request AbortSignal decoupled from persistent task cancellation; confirmed page creations and handovers commit incrementally, remaining recoverable after cancellation. JS help documents actual signatures and positional arguments, returning detached schema copies. Standard, fast, and action deltas share in-document observation pipelines, reusing cached state after checking DOM changes, control properties, CSSOM/media queries, Shadow DOM, focus, and layout; ambiguous state, budget overflows, and highlight requests trigger full extraction. Engine replacements sever observers, and fast hits flush transient layout caches. These changes require independent full gates, reload acceptance, and M7 tracking.

2026-10-29 Additions: The 221-character body of an X target post existed on live pages but was omitted in standard DOM observation. Root cause was an 80-character hard limit on non-interactive text leaves; nodes are now retained and bounded by `maxTextLength`. Card merging toggles, long paragraph truncation, and hidden/inert/script exclusions pass regression suites, keeping skill assertions intact; runtime acceptance requires updated builds.

1. While in-page snapshots retained 150 inputs, secondary action-record limits in the background truncated them to 125. Production merge regressions failed and subsequently passed; the 250 budget now constrains unique elements rather than splitting fill/click capabilities on the same node.
2. Receiving all frames does not guarantee all frames were observed. Coverage reports now reconcile `webNavigation.getAllFrames` against injected frame/document identities, explicitly flagging omissions, navigation races, and unverifiable states.
3. When partial frames are unreadable, unobserved nodes must not be inferred as deleted. Delta extraction preserves previous full baselines, returning incomplete coverage without false deletion outputs.
4. Upload module import chains prematurely captured uninitialized Native send functions. Switched to lazy invocation, handling rejections during startup, lease renewals, and reconnections to avoid unhandled background exceptions.
5. Updating the Native ledger alone is insufficient for tab handover: extension Agent registration must also be cleared. Core ownership release requires persistence; styling restorations like favicons report errors separately without regaining tab closure authority.
6. Initial full-frame injection during MDN observation hung on uncompleted child documents. Read-only observation now injects immediately per document; latest partial asset routing and full diff baselines are decoupled, avoiding deletion inferences for skipped frames.
7. Numeric literals in page JS were mistaken for references, triggering redundant DOM injections. Code without `mcp` references no longer creates reference bridges; unknown delivery across root, child, or scripting domains strictly rejects replay.
8. Tool category prompts broke JSON parsing in REPL environments. Raw content remains intact with business payloads parsed independently; locator fills support clearing, whitespace preservation, and default replacement.
9. Native reconnections that dispatched empty lease lists risked deleting files still actively referenced by pages. Reconnection now restores Native metadata before validating active document consumers; failure during enumeration or persistence avoids broadcasting empty authoritative lists.
