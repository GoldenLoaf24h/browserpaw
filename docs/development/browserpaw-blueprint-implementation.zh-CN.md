## 已复现并修复的集成问题

2026-10-30 观察与退出追加：第一层 fast 预算与后台跨框架预算须同时保留焦点、错误、动态提示和焦点所属表单／结果区域，同级候选继续公平轮转；标准分页使用同一优先级。fast 采集补齐 Shadow 根中的控件、正文及 scope/exclude 边界，ARIA 名称不再借用其他树的同名 ID。构造样式表对象替换即使 CSS 相同也使文档缓存失效。自建 REPL 客户端关闭前有界释放自己的 MCP 会话，不取消持久任务；外部注入客户端保持原关闭策略。当前这些改动仍处于开发验收，旧运行时已复现两个缺口，不能将专项测试或调用方绕行实验记为新运行时通过。

## 2026-10-28 观察语义、接管与截图约束

- 接管确认等待原任务的在途调用及账本更新；finish 在任何关闭或交还动作之前检查所有 owned 文档。未确认的导航不能被本地账本伪记为已交还，取消后的任务也不会凭旧身份清理页面。
- fast 与 standard 共用原生 validity、required、ARIA invalid 和关联错误的采集；fast 默认文本复用 compact 渲染器，包含校验消息、checkbox 状态及原生 select 的当前选项。一个元素的多种操作仍共享一个预算名额。
- 表格观察保留行列及表头关系，默认文本显示 aria-sort；同一行的移动和排序方向改变进入 delta。局部捕获缓存只在一次采集中复用，不能跨采集保留旧表结构。
- delta 基线绑定观察区域、排除规则和视口范围；范围或表示改变时明确返回完整基线，不将原区域节点误记为删除。状态比较使用完整已采集值，输出长度限制不参与判断是否发生变化。
- 截图坐标必须引用明确的 captureId，并在实际派发前检查文档、DOM revision、视口、DPR、滚动和缩放上下文。语义定位未使用截图 fallback 时，不受无关旧截图影响。批量坐标遇到变化即停止后续动作；Canvas、视频、纯 CSS 动画及跨源框架 DOM 不在完整可观测保证内。
- 真实文件已完成超过一小时的逐字节读取与释放，并单独验证 Native 重启后的消费者恢复；详见外层 `lease-longevity-state.json` 和 `lease-native-restart.json`。原生系统窗口缩放、最小化和 popup 焦点保证仍未验收。

## 技能闭环的责任边界

当前调用 Agent 负责在已验证成功的读取任务后提炼候选。Native 保存、校验和执行，不引入隐藏学习模型。每个候选具有参数、可执行步骤、输出契约、来源和复测输入；复测通过后自动切换正式版本。一次新候选失败不能替换既有可用版本。

独立复测还要通过单独的 DOM 或 GET 观察断言。自动执行只接受本地可信发布程序体，以及数据配置的 `dom-extract` 模板；调用方不能用 `source.type` 声明或字符串黑名单自行取得执行资格。任意代码和写盘等副作用参数在浏览器任务创建前拒绝。技能只在当前授权范围读取信息；X 缺少可用登录环境时只能记 blocked。
