# Repository map

| Directory              | Responsibility                                                |
| ---------------------- | ------------------------------------------------------------- |
| `app/native-server`    | CLI, Native host, installer, task state and recipe execution  |
| `app/chrome-extension` | Browser observation, native input, file and browser events    |
| `packages/shared`      | Command registry, browser executor contracts and common types |
| `skills/browserpaw`    | Canonical Agent Skill                                         |
| `plugins`              | Distributable Skill mirrors                                   |
| `test/live`            | Installed CLI and Chrome for Testing integration              |
| `docs/releases`        | Versioned release record                                      |
