# BrowserPaw npm package

Install with `npm install -g browserpaw` or run `npx browserpaw setup` once the package is published. Use `browserpaw setup` to install the local host and Agent Skill (`~/.agents/skills/browserpaw` by default, or `browserpaw setup --skill-scope project` for `./.agents/skills/browserpaw`). In `chrome://extensions`, turn on Developer mode and load the extension at the path printed by setup.

Run `browserpaw status` to verify the connection, `browserpaw recipe find` to inspect learned workflows under `~/.browserpaw`, and `browserpaw help` to discover commands.
