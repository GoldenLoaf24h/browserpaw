# BrowserPaw commands

Run `browserpaw help COMMAND` for help from the installed version.
Page commands take `--tab ID` or `--task ID`. Use `--frame ID` on frame-aware commands.
`--json` emits a single receipt. Use `--` before an argument starting with a dash.

Targets: 12 (observed ref), css:SELECTOR, text:TEXT, role:ROLE[:NAME], label:LABEL, or @X,Y --capture ID. Use --frame ID to select a frame. After navigation or a stale ref, observe again.

| Command                                                                                                                                                                                                                          | Purpose                                                                                              |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `setup [--browser BROWSER] [--skill-scope SCOPE] [--skill-dir DIR] [--no-skill]`                                                                                                                                                 | Install or refresh the host and base Skill. Prepare the bundled extension on first setup only.       |
| `status`                                                                                                                                                                                                                         | Show local host and extension connection and build identity.                                         |
| `doctor [--fix]`                                                                                                                                                                                                                 | Diagnose installation and connection. Use --fix to repair registration.                              |
| `uninstall [--purge]`                                                                                                                                                                                                            | Remove the managed installation. Purge also removes its user data.                                   |
| `help [COMMAND\|TOPIC]`                                                                                                                                                                                                          | Show usage and examples without opening Chrome.                                                      |
| `open URL [--foreground]`                                                                                                                                                                                                        | Open a new tab. --foreground applies only to non-task opens.                                         |
| `nav URL\|back\|forward\|reload`                                                                                                                                                                                                 | Navigate the selected page.                                                                          |
| `tab focus ID`                                                                                                                                                                                                                   | Bring the selected tab to the foreground.                                                            |
| `tab close ID...`                                                                                                                                                                                                                | Close explicitly named tabs.                                                                         |
| `observe [--scope CSS] [--delta] [--max N]`                                                                                                                                                                                      | Read page structure, frame IDs, and actionable refs.                                                 |
| `find PATTERN [--regex] [--scroll]`                                                                                                                                                                                              | Find matching elements in the page.                                                                  |
| `screenshot [TARGET] [--full] [--out FILE]`                                                                                                                                                                                      | Save an image locally and return its capture ID.                                                     |
| `wait [TARGET] [--text TEXT\|--url URL] [--gone] [--timeout MS]`                                                                                                                                                                 | Wait for a target, page text, or URL condition.                                                      |
| `click TARGET [--double\|--right] [--capture ID]`                                                                                                                                                                                | Click the target from the current observation or capture.                                            |
| `fill TARGET TEXT [--append] [--input FILE\|-]`                                                                                                                                                                                  | Replace or append text. Use -- before option-like text.                                              |
| `hover TARGET [--capture ID]`                                                                                                                                                                                                    | Move the pointer to a target.                                                                        |
| `press KEYS [TARGET]`                                                                                                                                                                                                            | Send a key sequence, optionally to a strict target.                                                  |
| `drag FROM TO [--capture ID]`                                                                                                                                                                                                    | Drag between two observed refs or capture coordinates.                                               |
| `upload TARGET FILE...`                                                                                                                                                                                                          | Choose local files for the specified input.                                                          |
| `dialog accept\|dismiss [--id ID] [--text TEXT]`                                                                                                                                                                                 | Handle a dialog from the selected page.                                                              |
| `download [TARGET] [--url URL] [--out DIR] [--timeout MS]`                                                                                                                                                                       | Trigger and wait for a verified download from this page.                                             |
| `eval [CODE] [--file FILE\|-] [--timeout MS]`                                                                                                                                                                                    | Evaluate explicit JavaScript in the selected page.                                                   |
| `fetch URL [--method METHOD] [--header KEY:VALUE]... [--body BODY]`                                                                                                                                                              | Send an explicit request from the selected page.                                                     |
| `cdp METHOD [JSON]`                                                                                                                                                                                                              | Call a supported DevTools command in the selected tab.                                               |
| `ask-human MESSAGE [--timeout MS]`                                                                                                                                                                                               | Pause at a page and ask the user to intervene.                                                       |
| `task start NAME [--goal TEXT]`                                                                                                                                                                                                  | Start a durable task and return its ID.                                                              |
| `task list`                                                                                                                                                                                                                      | List local tasks.                                                                                    |
| `task status [ID]`                                                                                                                                                                                                               | Inspect task pages and known and uncertain outcomes.                                                 |
| `task finish [--keep ID]... [--keep-unknown]`                                                                                                                                                                                    | Close verified owned pages and preserve borrowed pages.                                              |
| `task cancel`                                                                                                                                                                                                                    | Stop the task without rolling back dispatched work.                                                  |
| `task borrow ID`                                                                                                                                                                                                                 | Associate an existing user tab with the task.                                                        |
| `task release ID`                                                                                                                                                                                                                | Hand an owned tab back to the user.                                                                  |
| `batch FILE\|-`                                                                                                                                                                                                                  | Run JSON argument arrays in order, stopping at the first failure.                                    |
| `recipe list [--url URL] [--query TEXT] [--all]`                                                                                                                                                                                 | List learned skills and saved workflows under ~/.browserpaw.                                         |
| `recipe find [QUERY...] [--url URL] [--all]`                                                                                                                                                                                     | Match learned skills and workflows by intent or URL.                                                 |
| `recipe show ID`                                                                                                                                                                                                                 | Inspect a learned skill or saved workflow and its inputs.                                            |
| `recipe run ID [KEY=VALUE...]`                                                                                                                                                                                                   | Run a learned skill or saved workflow with typed inputs.                                             |
| `recipe save FILE\|-`                                                                                                                                                                                                            | Save a learned workflow or propose a verified skill in ~/.browserpaw.                                |
| `recipe validate ID`                                                                                                                                                                                                             | Verify and activate a candidate skill in ~/.browserpaw.                                              |
| `recipe rm ID`                                                                                                                                                                                                                   | Remove a saved workflow or disable a learned skill.                                                  |
| `tabs [QUERY...] [--windows\|--content] [--limit N]`                                                                                                                                                                             | List windows and tabs or search titles and URLs. --content also searches loaded pages.               |
| `window list`                                                                                                                                                                                                                    | List browser windows with explicit window IDs.                                                       |
| `window open URL [--width N] [--height N] [--background]`                                                                                                                                                                        | Open a URL in a new browser window.                                                                  |
| `window focus ID`                                                                                                                                                                                                                | Focus one explicitly identified browser window.                                                      |
| `window close ID`                                                                                                                                                                                                                | Close one explicitly identified browser window.                                                      |
| `group list [--window ID] [--title TITLE]`                                                                                                                                                                                       | List tab groups and their explicit tab IDs.                                                          |
| `group create TAB... [--group ID] [--window ID] [--title TITLE] [--color COLOR] [--collapsed]`                                                                                                                                   | Create a tab group from explicitly named tabs, or add them to --group ID.                            |
| `group update ID [--title TITLE] [--color COLOR] [--collapsed]`                                                                                                                                                                  | Update one explicitly identified tab group.                                                          |
| `group ungroup TAB...`                                                                                                                                                                                                           | Remove explicitly named tabs from their groups without closing them.                                 |
| `group close ID`                                                                                                                                                                                                                 | Close agent-owned tabs in one explicitly identified tab group.                                       |
| `tab move TAB INDEX [--window ID]`                                                                                                                                                                                               | Move one explicitly identified tab to a zero-based index.                                            |
| `text [TARGET] [--links\|--media\|--content] [--max-chars N] [--limit N]`                                                                                                                                                        | Read page text, extract the main content, list links, or inspect one image or media element.         |
| `select TARGET [--list\|VALUE...]`                                                                                                                                                                                               | List available choices or select by value.                                                           |
| `scroll [TARGET] [--up\|--down\|--top\|--bottom] [--by PX] [--until TEXT\|--selector CSS] [--max N] [--step PX] [--timeout MS] [--regex]`                                                                                        | Scroll the page or a scroll container, optionally until text or a selector is found.                 |
| `dismiss [--max N]`                                                                                                                                                                                                              | Dismiss visible overlays on the selected page.                                                       |
| `history search [QUERY] [--since T] [--until T] [--limit N]`                                                                                                                                                                     | Find visited pages by text and time.                                                                 |
| `history visits URL [--since T] [--until T] [--limit N]`                                                                                                                                                                         | Read individual visits to an exact URL.                                                              |
| `history top [--since T] [--until T] [--limit N]`                                                                                                                                                                                | Rank hosts by visits among up to 200 recently matching URLs.                                         |
| `history rm [URL...] [--since T] [--until T] [--yes]`                                                                                                                                                                            | Remove exact URLs or a bounded time range with both dates and --yes.                                 |
| `bookmark tree [--folder ID_OR_PATH]`                                                                                                                                                                                            | List the bookmark tree or one folder subtree.                                                        |
| `bookmark search QUERY [--limit N]`                                                                                                                                                                                              | Find bookmarks and folders by title or URL.                                                          |
| `bookmark add URL [--title TITLE] [--folder ID_OR_PATH]`                                                                                                                                                                         | Add a URL to the selected bookmark folder.                                                           |
| `bookmark mkdir PATH [--folder ID_OR_PATH]`                                                                                                                                                                                      | Create folders under an existing root or selected folder.                                            |
| `bookmark mv ID --folder ID_OR_PATH [--index N]`                                                                                                                                                                                 | Move a bookmark or folder to an explicit destination.                                                |
| `bookmark rename ID TITLE`                                                                                                                                                                                                       | Rename a bookmark or folder.                                                                         |
| `bookmark rm ID... [--recursive]`                                                                                                                                                                                                | Remove selected entries. Nonempty folders require --recursive.                                       |
| `bookmark dedupe [--folder ID_OR_PATH] [--apply]`                                                                                                                                                                                | Preview exact duplicate URLs within each folder. --apply requires --folder.                          |
| `bookmark export --out FILE [--folder ID_OR_PATH] [--format FORMAT]`                                                                                                                                                             | Write a JSON or Chrome-importable HTML backup.                                                       |
| `downloads list [--limit N] [--state STATE]`                                                                                                                                                                                     | List recent Chrome downloads, optionally by state.                                                   |
| `downloads reveal ID`                                                                                                                                                                                                            | Show a completed download in the OS file manager.                                                    |
| `downloads rm ID [--file]`                                                                                                                                                                                                       | Erase one download record. --file also removes the downloaded file.                                  |
| `storage get [KEY] [--session]`                                                                                                                                                                                                  | Read an entry or list keys in the selected page storage.                                             |
| `storage set KEY VALUE [--session]`                                                                                                                                                                                              | Write one string into the selected page storage.                                                     |
| `storage rm KEY [--session]`                                                                                                                                                                                                     | Remove one entry from the selected page storage.                                                     |
| `storage clear [--session]`                                                                                                                                                                                                      | Clear the selected page origin and storage area.                                                     |
| `cookies list [--url URL\|--domain DOMAIN] [--values] [--limit N]`                                                                                                                                                               | List unpartitioned cookies in the default store. Values require an explicit scope.                   |
| `cookies set URL NAME VALUE [--path PATH] [--secure] [--http-only] [--same-site MODE] [--expires T]`                                                                                                                             | Set a host-only cookie in the default store.                                                         |
| `cookies rm URL NAME`                                                                                                                                                                                                            | Remove the unpartitioned cookie selected by Chrome for this URL and name.                            |
| `console [--level LEVEL] [--grep PATTERN] [--limit N] [--clear] [--no-exceptions]`                                                                                                                                               | Read buffered console output with level and text filters; --level accepts comma-separated levels.    |
| `network start [--filter PATTERN] [--bodies] [--static] [--max-time MS] [--idle MS]`                                                                                                                                             | Start a page recording. --filter matches captured request URLs. --bodies captures textual responses. |
| `network stop [--bodies]`                                                                                                                                                                                                        | Stop the selected page recording and return captured events.                                         |
| `network show [ID] [--out FILE]`                                                                                                                                                                                                 | Read captured network events, or inspect one request by ID. --out writes its textual body.           |
| `network list [--filter PATTERN] [--method METHOD] [--status CODE] [--type TYPE] [--limit N]`                                                                                                                                    | List captured requests with URL, method, status, type, and result-limit filters.                     |
| `network clear`                                                                                                                                                                                                                  | Clear the selected page network capture while leaving recording active.                              |
| `perf metrics`                                                                                                                                                                                                                   | Read Chrome performance counters for the selected page.                                              |
| `perf trace start\|stop\|analyze [NAME] [--reload] [--auto-stop] [--duration MS] [--out FILE]`                                                                                                                                   | Record, stop, or summarize a Chrome performance trace; trace files stay in the Native temp area.     |
| `emulate [--viewport WIDTHxHEIGHT] [--dpr NUMBER] [--mobile] [--user-agent TEXT] [--color-scheme SCHEME] [--timezone ID] [--locale LOCALE] [--cpu-rate NUMBER] [--offline] [--latency MS] [--download-kbps N] [--upload-kbps N]` | Apply device, media, locale, CPU, or network emulation to the selected page.                         |
| `emulate reset`                                                                                                                                                                                                                  | Clear viewport, media, locale, CPU, and network emulation on the selected page.                      |
| `pdf [--out FILE] [--landscape] [--no-background] [--paper PAPER] [--margin INCH] [--scale N] [--header] [--footer]`                                                                                                             | Print the selected page to PDF and save its bytes outside Agent context.                             |
